# Anagh Bajpai — Developer Portfolio

A responsive Next.js portfolio inspired by the code-editor / terminal aesthetic of anoopsonkriya.dev, personalized using the information in Anagh's resume.

## Run locally

Requirements: Node.js 18.17+ (Node 20 LTS recommended).

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customize before publishing

1. In `app/page.tsx`, replace the placeholder GitHub and LinkedIn URLs with your actual profile URLs.
2. Add the real live-demo and repository URLs for Roamwise, QuickCart, and Object Detection.
3. Connect the GitHub contribution section to your real GitHub profile if you want live contribution data.
4. Add a profile photo if desired; the current avatar is a typographic placeholder.
5. Review the copy and availability status before deploying.

## Deploy

Push the project to GitHub and import it into Vercel, or deploy with any platform supporting Next.js.

## Notes

- No fabricated contribution counts, uptime figures, or work metrics are included.
- Project descriptions and performance figures are based on the supplied resume.
- This is an independently implemented visual recreation, not the original site's source code.
